# Personal Topology · 个人人际拓扑

把你的「人物档案」渲染成一张可交互的星图：我居中，家人朋友同事按阶段铺开，点开一个人看档案，双击他则切换到「以他为中心」。

零后端、零外部依赖、单文件 HTML、离线可用。数据只在本机。

```
        初中
          ● 阿岚
      ● 老周        ● 陈默
         ╲   │   ╱
           ◉ 我  ──── ● 苏禾（工作室）
         ╱   │   ╲
      ● 何晓     ● 唐宁
          大学 / 工作
```

## 它解决什么问题

当档案（Markdown / 日记 / 笔记）攒到几十个人、上百条记录时，**表格看不出结构**：谁和谁一伙、谁是哪个阶段的人、谁离我最近。这个项目把那堆档案压缩成一张图，图只是索引，点开还是原来的档案。

## 快速开始

```bash
git clone <this repo>
cd personal-topology

# 用虚构示例数据构建
python3 build.py --data examples/demo --out examples/demo.html

open examples/demo.html        # macOS
# 或直接双击 examples/demo.html
```

构建产物是**单个 HTML 文件**，可以发给别人、放到任何静态服务器，或直接离线打开。

## 换成你自己的数据

```
data/
├── roster.json          # 阶段、人物、圈子、人际连线
└── people/
    ├── 阿岚.md
    └── 苏禾.md
```

```bash
python3 build.py --data data --out dist/topology.html
```

`data/` 默认被 `.gitignore` 忽略——**永远不要把真实人物档案提交到公开仓库**。

## 三条设计原则（为什么它长这样）

1. **图是档案的压缩视图。** 图上出现的每个人必须有一份档案；图上不承载档案里没有的信息。加人顺序：建档案 → 写 roster → 构建。
2. **一个视觉通道只表达一个维度。** 颜色=阶段、大小=出现次数、半径=亲疏、线型=关系类型；圈子不占颜色，只用悬停徽章。
3. **节点只讲事实。** 一行一件事、带日期、带来源；评价标注「本人评价」；不推断动机；第三方隐私默认不写。

完整规则见 **[SPEC.md](SPEC.md)**，它也是给 AI 助手/AI 编码工具读的规范——可以直接把 SPEC 喂给模型，让它按规则帮你补档案或改渲染。

## 交互

| 操作 | 效果 |
|---|---|
| 单击节点 | 右侧档案面板 |
| 双击节点 | 以他为中心重排 |
| 双击空白 | 回到「我」 |
| 悬停 | 高亮相关的人；圈内成员整组亮起 |
| 图例 | 按阶段筛选 |
| 滚轮 / 拖拽 | 缩放 / 平移 |

## 目录结构

```
build.py               # 构建：data/ → 单文件 HTML（仅标准库）
template/index.html    # 渲染引擎（内联 CSS/JS，纯手写 SVG）
schema/                # JSON Schema（编辑器校验用）
examples/demo/         # 虚构示例数据
examples/demo.html     # 示例产物
tests/                 # python -m pytest
SPEC.md                # 数据模型 + 口述规则 + 视觉编码 + 交互
```

## 隐私

- 没有后端、没有网络请求、不上传任何数据。
- 示例数据全部虚构；`data/` 已被忽略。
- 导出前请自行脱敏：手机号、邮箱、社交账号、住址。
